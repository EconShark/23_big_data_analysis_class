# Python/Pandas for Business Analytics

## Mục tiêu
Bài thực hành mở đầu cho học phần Phân tích dữ liệu lớn trong đầu tư và kinh doanh.
Sinh viên sử dụng Python, NumPy và Pandas để làm sạch, khám phá và phân tích dữ liệu kinh doanh trước khi chuyển sang PySpark.

## Cấu trúc
- `Python_Pandas_for_Business_Analytics.docx`: handout.
- `Python_Pandas_for_Business_Analytics.ipynb`: notebook thực hành.
- `data/business_sales_dirty.csv`: dataset thực hành (~30.000 giao dịch).
- `DATA_DICTIONARY.csv`: mô tả trường dữ liệu.

## Cài đặt
```bash
pip install pandas numpy matplotlib
```

## Cách chạy
1. Giải nén thư mục.
2. Mở notebook bằng Jupyter Notebook, JupyterLab, VS Code hoặc Google Colab.
3. Giữ notebook cùng cấp với thư mục `data/`.
4. Chạy lần lượt từ trên xuống.

## Nội dung
Python cơ bản, NumPy, Pandas Series/DataFrame, đọc CSV, data quality, cleaning,
filtering, groupby, pivot table, merge, datetime, KPI, EDA, visualization,
customer/product/channel analysis và business insights.

## Lưu ý
Dataset là dữ liệu mô phỏng phục vụ giảng dạy, có cài missing values, duplicate,
category không nhất quán, giá trị bất hợp lệ và return transaction có chủ đích.
