Ứng dụng Generative AI trong công việc Data Analyst

Bộ tài liệu gồm:
1. Ung_dung_Generative_AI_trong_cong_viec_Data_Analyst.pdf
   - Hướng dẫn thực hành, minh họa demo, yêu cầu nộp và rubric.

2. Ung_dung_GenAI_trong_cong_viec_Data_Analyst.ipynb
   - Notebook dành cho sinh viên.

3. Demo_da_chay_GenAI_Data_Analyst.ipynb
   - Bản notebook đã chạy để giảng viên tham khảo/demo.

4. business_transactions.csv
   - 12.080 dòng, gồm dữ liệu cấu trúc + ReviewText.
   - Có chủ động cài missing, duplicate và một số bất thường để thực hành.

5. Bo_prompt_mau_GenAI_Data_Analyst.md
   - 14 prompt mẫu, gồm EDA, code, cleaning, debug, insight,
     visualization, ReviewText, Executive Summary, hallucination test
     và self-check.

Cách dùng:
- Đặt CSV cùng thư mục với notebook.
- Chạy notebook tuần tự.
- Copy prompt sang công cụ GenAI.
- Ghi Prompt Log và kiểm chứng mọi kết quả AI bằng Python/dữ liệu gốc.
